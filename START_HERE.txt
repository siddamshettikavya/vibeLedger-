VIBELEDGER - PROFESSIONAL NETWORKING WEBSITE

Includes a LinkedIn-inspired (original, not affiliated) professional layout.
Features: registration/login/logout, people search, skills, connections,
skill swaps, posts/feed, Proof of Vibe portfolio, peer attestations/reviews,
reputation, resume upload/download, and Socket.IO real-time refresh.

Run:
1. Extract ZIP.
2. Open folder containing package.json in VS Code.
3. PowerShell: npm.cmd install
4. PowerShell: npm.cmd start
5. Open http://localhost:3000
